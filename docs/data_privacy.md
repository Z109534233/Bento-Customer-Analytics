# Data Privacy

The operational project used private POS/order data. This public portfolio repository intentionally does **not** include:

- customer names
- phone numbers
- invoice/tax identifiers
- raw order exports
- production server addresses
- database credentials
- login credentials
- SSH/deployment keys
- private API keys

All files in `sample_data/` are synthetic and generated by `scripts/generate_synthetic_data.py` with a fixed random seed for reproducibility.

The SQL schema in `sql/schema.sql` uses anonymous `customer_id` values rather than personal identifiers.
